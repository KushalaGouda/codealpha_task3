# Matrix Operations in C

## 📌 Overview
This project implements basic matrix operations using **functions and 2D arrays** in C.  
The operations included are:
- Matrix Addition
- Matrix Multiplication
- Matrix Transpose

It was developed as part of the CodeAlpha internship tasks.

---

## ⚙️ How to Run
1. Open a terminal in the project folder.
2. Compile the program:
   ```bash
   gcc matrix.c -o matrix
